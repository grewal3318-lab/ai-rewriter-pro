# AI Rewriter Pro

This repository is the home for the privacy policy page of AI Rewriter Pro, a browser extension.

## What is AI Rewriter Pro

AI Rewriter Pro is a browser extension that lets someone highlight text on any webpage and have it rewritten by an AI service of their choice, such as Claude, ChatGPT, Gemini, or OpenRouter. The person using it brings their own account and their own API key for whichever service they pick, and they can save up to 15 of their own custom rewrite prompts. Everything stays on their own device, the extension does not collect or store any of it.

## What is actually in this repository

Right now this repository holds one page, `privacy.html`, which is the extension's privacy policy. It explains, in plain terms, what the extension does and does not do with a person's data, where API keys and prompts are stored, and that selected text is sent only to the AI service the person has chosen, never to the extension's developer.

This repository does not contain the extension's code itself, only this policy page.

## How to use this repository

There is nothing to install or run here. To read the privacy policy, simply open the `privacy.html` file in a web browser, either by opening the file directly or, if this page has been published online, by visiting its web address. It is a plain webpage meant to be read, not a program.

## Who to contact

Any questions about the privacy policy can be sent to the contact address listed at the bottom of the `privacy.html` page.
